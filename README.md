🚀 Sobre o Projeto

Este projeto é uma página de portfólio pessoal, desenvolvida inicialmente com HTML5 e CSS3, e posteriormente aprimorada com JavaScript para adicionar interatividade e melhorar a experiência do usuário.

O objetivo é apresentar de forma clara e profissional:

Informações pessoais
Experiência e transição de carreira
Projetos desenvolvidos
Contatos profissionais
🛠️ Tecnologias Utilizadas
HTML5 → Estrutura semântica da página
CSS3 → Estilização, layout e responsividade
JavaScript (Vanilla) → Interatividade e manipulação do DOM
⚙️ Funcionalidades
✅ Botão "Ver mais / Ver menos" na seção "Sobre mim"
✅ Exibição dinâmica dos projetos
✅ Efeito interativo com hover para descrição adicional
✅ Layout centralizado e organizado
